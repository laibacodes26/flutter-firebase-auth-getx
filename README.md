# Flutter CRUD App

A complete CRUD application developed during my Flutter internship at Big Brains.

## Technologies

- Flutter
- Dart
- GetX
- Firebase Cloud Firestore
- MVC Architecture

## Features

- Create users
- Read users from Firestore
- Update user information
- Delete users
- Form validation
- Confirmation dialogs
- GetX reactive state management
- GetX navigation
- Snackbars
- MVC architecture

## CRUD Operations

### Create
Add user information including:
- Name
- Email
- Age

### Read
Fetch and display users from Firebase Cloud Firestore.

### Update
Edit existing user information and update the corresponding Firestore document.

### Delete
Delete users after confirmation.

## Architecture

The application follows the MVC architecture:

lib/
├── controllers/
├── models/
├── views/
└── main.dart
